Interchangeable groups running low

A group is a set of products the HPRA considers substitutable for one another. When a group is down to one product, every patient on that medicine depends on a single supplier. Brand names hide this: a shortage listed under a brand gives no clue which group it belongs to, or how much of that group is already gone.

Why this is sometimes empty. The register is not updated every day. We collect it each morning and compare against our previous collection, so on a day the HPRA has not changed anything this section is simply empty.

There is also a day's lag in collection: a Saturday capture carries Friday's activity. And the HPRA occasionally reissues a shortage under a new reference number without anything else changing. Those are not listed as changes, because nothing happened to the medicine.

How this is collected

Nothing on this page is clinical guidance.

  • Every morning an automated system reads the HPRA medicine shortage register, the same public information shown on the HPRA website, and stores a dated copy of it.
  • Weekly, it reads the HPRA List of Interchangeable Medicines, which defines which products the regulator considers substitutable for one another.
  • Each shortage is matched to its interchangeable group by licence number. That match is what lets us say whether alternatives exist and how many are still available.
  • How long a shortage has been running is measured from the date the HPRA was notified. A separate field records when supply is expected to be affected, which for some entries is still in the future.
  • Where the register links a supply notice from the company that markets the medicine, we carry the link through to the original document on the HPRA site. We do not summarise, date or interpret these notices. Read them at source.
  • The register only shows the present day. Because we keep every day's copy, we can show what appeared, what quietly disappeared, and which return dates moved. It does not change every day, so we compare against the last day it actually moved rather than against yesterday.
  • We publish our own analysis of the register, not a copy of the register. The HPRA holds the authoritative list.
  • We do not access any private data, we do not alter the HPRA's information, and nothing on this page is clinical guidance.
